## Rules
* `declareWar` fails with `NOT_ADJACENT` unless the target region has a neighbour that the attacker's country owns **right now** (checked inside the transaction).
* After a war is won the region changes owner, so the front line moves with the conquest.
* A country that owns no region at all may target any region (otherwise a country that lost everything could never come back).
* `rc_config/war` -> `{ "requireAdjacency": false }` switches the rule off without a deploy.
* Neighbour counts: 651 regions, 1550 links (1451 land, 81 sea, 18 bridges). Change the sea distance with `SEA_KM=150 node tools/gen-war-map.js`.
